# Changelog

All notable changes to this project are documented here. The format follows [Keep a Changelog](https://keepachangelog.com/en/1.1.0/), and the project aims to follow [Semantic Versioning](https://semver.org/) from 1.0.

## [0.1.0] - 2026-11-22

Initial public release.

### Added
- 48 React 19 + TypeScript components: layout, navigation, actions, inputs, display, feedback and overlays.
- Glass surfaces, spring motion, push/pop navigation with swipe-back, sheets with detents, menus, pickers and charts.
- Light, dark and high-contrast palettes, RTL, and 12 text-size steps.
- 198 icon names built on Lucide, with `registerIcons` for custom icons.
- Bundled Inter variable font as the cross-platform fallback.
- Playground with every component screen, six sample flows, and machine-readable `catalog.json`, `intents.json` and `rules.md`.
- CI (typecheck, 23 validation checks, legal-term audit, playground build) and a GitHub Pages deploy of the playground.
